# Bella Vita Restaurant

A Next.js app scaffold for a restaurant website with pages for about, menu, gallery, reservations, and contact.

## Structure

- `app/` — application routes and pages
- `components/` — reusable UI components
- `data/` — mock data for menus, testimonials, chefs, gallery, and FAQ
- `hooks/` — custom React hooks
- `lib/` — utility helpers and constants
- `public/` — static assets
- `styles/` — global and shared styles
- `types/` — TypeScript type definitions

## Setup

```bash
npm install
npm run dev
```
